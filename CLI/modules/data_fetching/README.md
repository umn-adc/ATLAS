Data Fetching Library for the ATLAS trading program.
Contains the start_data_fetch function, which begins pulling data from Alpaca for
the requested tickers.

# Dependencies:
[Cmake 3.15 (or newer)](https://cmake.org/download/)

# Building:
In a terminal:
<cmake -b build> (configure)
<cmake --build build> (build)

To run the example file:
<./build/example> (Linux/Mac)
<./build/example.exe> (Windows)
